## Positioning

"My agent skills that I use every day to do real engineering - not vibe
coding." Skills are small, composable, adaptable and model-agnostic rather than
a heavy end-to-end methodology.

## Failure modes and the skills that address them

| Failure mode | Fix |
|---|---|
| Building the wrong thing | a **grilling session**: the agent asks detailed questions until the design is sharp |
| Verbose, ambiguous communication | a shared language / glossary, built into `/grill-with-docs` (ADRs + glossary) |
| Wrong code | `/tdd` — red-green-refactor loop |
| Bugs without a method | `/diagnosing-bugs` — reproduce, minimise, hypothesise, instrument, fix, regress |
| Big-ball-of-mud architecture | architecture / codebase-design skills |
